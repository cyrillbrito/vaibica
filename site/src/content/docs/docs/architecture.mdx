Bica is three packages: the Solid client, a plain Bun server, and the code they share.

```d2 title="Bica's packages and where they run"
direction: right

browser: Browser {
  client: "client\nSolid 2"
}

machine: Dev machine {
  server: "server\nBun"
  db: "SQLite\nPi Durable" {shape: cylinder}
  worktrees: worktrees {shape: page; style.multiple: true}
  server -> db
  server -> worktrees: tools run here
}

model: Model provider {shape: cloud}

browser.client <-> machine.server: WebSocket {style.animated: true}
machine.server <-> model: HTTPS
```

<Aside type="tip">
  The client never talks to the model. Everything goes through the server, so a
  session keeps running when you close the tab.
</Aside>
