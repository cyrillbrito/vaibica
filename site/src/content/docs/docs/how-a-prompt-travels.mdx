## The same flow as a sequence

```d2 title="A prompt as a sequence diagram"
shape: sequence_diagram
you: You {shape: person}
client: Client
server: Server
durable: Pi Durable
model: Model

you -> client: Enter
client -> server: prompt request
server -> durable: start turn
durable -> model: messages
streaming: Streaming {
  model -> durable: tokens, tool calls {style.stroke-dash: 3}
  durable -> server: events {style.stroke-dash: 3}
  server -> client: transcript updates {style.stroke-dash: 3}
}
```

## The same flow, animated

D2 can pack several boards into one SVG and step through them on a timer, with no script on the page.

```d2 animateInterval=1400 title="A prompt moving through Bica"
direction: right
client: Client
server: Server
durable: Pi Durable
model: Model

client -> server: prompt {style.opacity: 0.25}
server -> durable: start turn {style.opacity: 0.25}
durable -> model: messages {style.opacity: 0.25}

scenarios: {
  send: {
    (client -> server)[0].style: {stroke: "#d99a5b"; stroke-width: 4; opacity: 1}
  }
  turn: {
    (server -> durable)[0].style: {stroke: "#d99a5b"; stroke-width: 4; opacity: 1}
  }
  ask: {
    (durable -> model)[0].style: {stroke: "#d99a5b"; stroke-width: 4; opacity: 1}
  }
  stream: {
    model -> durable: tokens {style: {stroke: "#d99a5b"; animated: true}}
    durable -> server: events {style: {stroke: "#d99a5b"; animated: true}}
    server -> client: transcript {style: {stroke: "#d99a5b"; animated: true}}
  }
}
```
