Bica is a fast web UI for coding agents. The server runs on your dev machine, and the UI works from any browser.

<CardGrid>
  <Card title="Many sessions" icon="list-format">
    Stream, steer, and queue prompts across a dozen agents at once.
  </Card>
  <Card title="Worktrees" icon="seti:git">
    Each feature gets its own branch and folder.
  </Card>
  <Card title="Review" icon="document">
    Full-screen diffs, with comments that go back to the agent.
  </Card>
  <Card title="Remote first" icon="phone">
    Use it from your phone over Tailscale.
  </Card>
</CardGrid>
