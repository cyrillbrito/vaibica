# Name exploration

Tau is the working name, not a final choice. The current favorite is Bica Codes, with `bica.codes` as its possible home. Keep Pipoca, Piu, and Tau in consideration rather than renaming the app yet. The name should be short, easy for English speakers to say, personal or playful, and not a generic OpenPi or PiUI variant.

## Names worth keeping

- Bica Codes keeps the Lisbon espresso reference and makes the domain part of the name. A possible convention is Bica Codes for the project, `app.bica.codes` for the UI, and `api.bica.codes` only if a public API exists. An icon could combine a coffee cup with a small code mark; check its legibility at phone size.
- Tau is still preferred over many alternatives. `tau.cafe` gives it a memorable address without changing the spoken name; Taucan, Taupoca, and Tau Bica were playful variations, not decisions.
- Pipoca means popcorn, starts with Pi, and is playful. Portuguese is roughly “pee-POH-kah”; English speakers may say “pi-POH-kuh” or “pie-POH-kuh.”
- Piu echoes Pi + UI and a bird chirp. English readers may say “pee-oo,” “pie-you,” or “pew.”
- Miso, Tetra, and Quanta appealed as short alternatives, but the research below makes them harder to use. Nimble also sounded good but has a close conflict.

## Conflicts found

- [Hugging Face's Tau](https://github.com/huggingface/tau) is itself a Pi-inspired coding agent. [Another Tau](https://tau-agent.dev/) is also a coding agent. A distinctive domain will not prevent people from calling this tool just “Tau.”
- [Bica](https://bica.works/) builds AI automation and custom software, [Bica for Figma](https://bicaforfigma.com/) is a UI kit, and [Bika.ai](https://bika.ai/) is a similarly pronounced AI-agent platform. No prominent coding-agent UI called exactly Bica turned up in the searches, but the name is not clear of conflicts.
- [Pipoca](https://github.com/Kruceo/Pipoca) is also a versioning tool. An unrelated [PIU app](https://piu.com.br/) uses Piu.
- [Miso](https://miso.ai/) is an AI search company and [another Miso](https://www.misojs.dev/) is a developer CLI. [Nimble](https://gitnimble.com/) is already an AI-aware Git client.
- [Quanta Code](https://datanito.com/quanta-code) is an agentic development environment, and [another Quanta](https://github.com/ContegoCode/Quanta-Code-Editor) is a coding agent/editor. Tetra is widely used in software; [Tetra Science](https://developers.tetrascience.com/) is one example. [Tau Studio](https://github.com/OnionIoT/tau-lidar-server/blob/master/GET-STARTED.md) already names a web app.

## Domains to revisit

- `bica.codes`, `bica.cafe`, `bica.run`, `bica.place`, `bica.ink`, `bica.garden`, and `bica.chat` are the most promising Bica domain ideas. BicaCodes sounds more like a consultancy, and Bica Agent implies the UI is itself the agent. `.ui` is not a delegated top-level domain.
- `tau.cafe`, `tau.fun`, `tau.work`, `tau.pizza`, `taudesk.app`, and `taucan.app` keep Tau in view. `tau.app`, `tau.dev`, and `tau.ai` were registered at the time of checking.
- `pipoca.dev`, `pipocacode.dev`, `pipoca.party`, `piudesk.app`, `misodesk.app`, `tetrawork.app`, and `quantadesk.app` were other domain-backed ideas. Do not mistake a distinctive URL for an unencumbered product name.
- Registry lookups returned “not found” for `bica.codes`, `tau.cafe`, `tau.fun`, `tau.work`, and several other candidates during this exploration. That is not a purchase, an availability guarantee, a price quote, or trademark clearance. Check the full registration and renewal prices at a registrar before deciding. [Cloudflare supports `.codes`](https://domains.cloudflare.com/tld-policies); its logged-in search page could not be accessed in the research browser.

## Discoverability

[Pipoca has the clearest coding-agent search space](https://github.com/Kruceo/Pipoca) among the names we liked. Bica has more nearby AI and software businesses; Tau has direct coding-agent collisions; Quanta Code has direct competitors. This is a comparison of web search results, not measured traffic, search volume, or a trademark assessment. [Google says domain keywords and generic TLD choice have little ranking effect](https://developers.google.com/search/docs/fundamentals/seo-starter-guide), and [recommends a distinct, concise site name](https://developers.google.com/search/docs/appearance/site-names). Choose a name people will remember before choosing an extension.
